# BDD Gherkin Skill
## Activation
Use when acceptance criteria should become BDD scenarios or when feature files need review.
## Inputs
User story, acceptance criteria, or test cases.
## Procedure
1. Identify actor, preconditions, behavior, and observable outcome.
2. Create concise scenarios using Given/When/Then and And.
3. Avoid UI implementation details and ambiguous steps.
4. Include negative and alternate flows where justified.
5. Check each scenario against the source requirements and flag assumptions.
## Output
Feature file text, assumptions, and coverage notes.
